Doc-ready Section 13.5 paragraph

A subset of 96 trials (20.1% of the formal dataset) was blindly re-annotated by the same researcher after a minimum interval of two weeks, with the initial labels withheld during the second annotation pass. Intra-rater reliability was evaluated using Krippendorff’s alpha. Agreement for primary RC label coding was α = 0.801. Agreement for transformation-intensity coding was α = 0.802. Agreement for binary recomposition-signature coding was α = 0.779. Agreement for the interpretive-stabilization marker was also α = 0.779. These results indicate generally substantial to high within-researcher coding stability. Because the study used a single annotator, these values should be interpreted as evidence of within-researcher coding consistency rather than inter-rater generalizability.
